## ADDED Requirements

### Requirement: A relocation names the member it made
An accepted relocation stating the target handle SHALL land the destination's create on that handle in the write recording the outcome, never leaving it delivered for a listing to land on another member stating its link id (folded into cairn/spec/sync.md).

### Requirement: A server object id decides where both state one
A `Full` upgrade SHALL link a body only from a holder whose binding of the same source states the placement's server object id where both state one (folded into cairn/spec/upgrade.md and cairn/spec/seam.md).
